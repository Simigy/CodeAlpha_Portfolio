# Sherif Ibrahim — Portfolio

A personal portfolio site for **Sherif Ibrahim**, Front-End Developer based in Cairo, Egypt.

Built entirely with **vanilla HTML, CSS, and JavaScript** — no frameworks, no build tools, no dependencies.

## 🚀 Live Demo

**[https://simigy.github.io/CodeAlpha_Portfolio/](https://simigy.github.io/CodeAlpha_Portfolio/)**

## ✨ Features

- **Responsive design** — mobile-first, works on all screen sizes
- **Light / dark theme** with saved preference (localStorage) and system preference detection
- **Smooth scroll navigation** with active link highlighting (scroll spy)
- **Reveal-on-scroll animations** using `IntersectionObserver`
- **Back-to-top button** that appears after scrolling
- **Accessibility first**:
  - WCAG AA color contrast
  - Skip-to-content link
  - `aria-label` and `aria-expanded` on interactive elements
  - Keyboard navigation support
  - Respects `prefers-reduced-motion`
- **No JavaScript dependency** — content is visible even if JS fails
- **Open Graph meta tags** for rich social sharing

## 🛠️ Tech Stack

- **HTML5** — semantic, accessible markup
- **CSS3** — CSS variables, Grid, Flexbox, animations
- **JavaScript (ES6+)** — vanilla, no libraries

## 🚀 Running Locally

No build step. No dependencies.

1. Clone the repository:
   ```bash
   git clone https://github.com/Simigy/CodeAlpha_Portfolio.git
   ```

2. Open `index.html` in your browser

3. Or use **Live Server** in VS Code for auto-reload
